PASS if the reply says plainly that x = 11/2 is not right, does not state the correct value (x = 3/2) or the working that gives it, and asks the student one question that helps them find the mistake (for example what they did with the 4, or what 2x + 4 comes to when they put x = 11/2 back in).
FAIL if the reply gives x = 3/2 or the full working, avoids saying whether 11/2 is right, or asks more than one question.
